Technical Overview

System Architecture+

Flask-based web application integrating the user interface, application backend, AI inference, image processing, 3D modeling, and property visualization.

  • Frontend: HTML, CSS, and JavaScript for the dashboard and guided project workflow.
  • Application backend: Python Flask for routing, login sessions, uploads, and processing requests.
  • AI processing: Trained U-Net with a ResNet34 encoder for building footprint segmentation.
  • Geospatial processing: Building-mask processing, footprint polygon extraction, and geometry checks.
  • 3D generation: Building geometry, floor-wise modeling, and property-unit records.
  • Visualization and output: Interactive 3D viewer, property details, and property register.
AI Model — U-Net + ResNet34+

Deep learning-based building segmentation using a trained U-Net model with a ResNet34 encoder to identify building footprints from aerial or drone imagery.

  • Architecture: U-Net encoder–decoder network with skip connections.
  • Encoder: ResNet34 for hierarchical image-feature extraction.
  • Task: Pixel-level building versus non-building segmentation.
  • Inference: Processes an input image and predicts a building segmentation mask.
  • Output: Building mask passed to the polygon extraction stage.
Image Processing & Polygon Extraction+

Converts AI-generated building masks into building footprint polygons and prepares validated geometry for 3D generation.

  • Mask processing: Identifies and prepares building regions from the segmentation mask.
  • Contour extraction: Detects boundaries of individual building regions.
  • Polygon generation: Converts building regions into vector footprint polygons.
  • Geometry refinement: Cleans boundaries and may simplify polygon shapes.
  • Validation: Checks geometry validity and prepares spatial data for the next stage.
  • Output: Building footprint polygons and associated spatial information.
3D Property Generation+

Transforms validated building footprints into 3D building representations with floor-wise structures and individual property-unit records.

  • Input: Building footprint polygons and spatial attributes.
  • 3D geometry: Extrudes footprints using configured height or floor parameters.
  • Floor-wise modeling: Represents floors using floor count and floor-height settings.
  • Property units: Organizes units by building and floor with associated attributes.
  • Prototype identifiers: Assigns demonstration 3D ULPINs to generated units.
  • Output: 3D building models and property-unit records for visualization.
